# Life OS

Life OS is a personal productivity dashboard built with HTML, CSS, and JavaScript. It brings together everything you need for your daily routine in one place—including a Pomodoro timer, task list, habit tracker, quick notes, event planner, focus analytics, custom quick links, ambient audio, and an embedded Spotify player. It also features a switchable design with Cyberpunk, Antique, and Light theme options, plus a built-in retro Snake arcade game for quick breaks. Everything saves automatically in your browser so your setup is always ready to go.

# How It Was Built
The project was engineered using standard vanilla web technologies to keep performance instantaneous and lightweight.

HTML5: Structured into a responsive grid system featuring 12 individual dashboard cards and widgets.

CSS3: Utilizes dynamic CSS custom properties (variables) to control theme modes, grid layouts, custom scrollbars, and card highlights seamlessly.

JavaScript (ES6+): Handles all state calculations, real-time clock tickers, event handling, dynamic DOM creation, dynamic API fetching for daily quotes, and Spotify URL parsing.

Local Storage API: Serves as the persistence layer to store focus session histories, tasks, notes, active themes, and custom configuration settings locally on your machine.


# Features Overview
Multi-Theme Engine: Dynamic switching between Cyberpunk, Antique, and Light visual modes.

Live Clock & Date: Real-time clock updating every second with date context.

Pomodoro Timer: Functional focus countdown timer with start, pause, and reset controls.

Focus Analytics & Streaks: Automatic calculation of completed sessions, total minutes, and daily streak persistence.

Interactive Task Manager: On-the-fly task creation and deletion.

Habit Tracker Matrix: Daily checkable habits with visual progress tracking.

Quick Notes Scratchpad: Persistent text area for code snippets, ideas, and reminders.

Event Planner: Date-tagged logger for appointments and calendar events.

Custom Quick Links: Bookmark launchpad for your most visited websites.

Focus Audio Player: Ambient sound controls for background study noise.

Live Weather Status: On-screen weather display tracking temperature and location parameters.

Spotify Podcast & Audio Streamer: Embedded media player configured for inline audio streaming.
