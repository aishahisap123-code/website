# Life OS

Life OS is a personal productivity dashboard built with HTML, CSS, and JavaScript. It brings together everything you need for your daily routine in one place—including a Pomodoro timer, task list, habit tracker, quick notes, event planner, focus analytics, custom quick links, ambient audio, and an embedded Spotify player. It also features a switchable design with Cyberpunk, Antique, and Light theme options, plus a built-in retro Snake arcade game for quick breaks. Everything saves automatically in your browser so your setup is always ready to go.
